# AgentDispute Frontend\n\nFrontend for the deployed AgentDispute GenLayer intelligent contract.\n\nContract: `0xd21c82603a64Bd42ff37FB04cD004699c6A4BbeA`\n\n## Routes\n- `/` — overview\n- `/create` — create and fund an agreement\n- `/disputes` — browse on-chain agreements\n- `/disputes/[id]` — submit evidence, evaluate, cancel, expire, and settle\n\n## Setup\n```bash\nnpm install\nnpm run dev\n```\n\nOptional `.env.local`:\n```env\nNEXT_PUBLIC_CONTRACT_ADDRESS=0xd21c82603a64Bd42ff37FB04cD004699c6A4BbeA\n```\n\nThe app uses `genlayer-js@1.1.8` and the `studionet` chain configuration (chain ID `61999`). The frontend can add/switch MetaMask to GenLayer Studionet automatically.\n
